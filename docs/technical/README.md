# Serial Brain 技术文档

Serial Brain 是一套基于 Tauri、Rust 与 Vue 的八通道信号采集及视频录制应用。系统将串口或 TCP 字节流转换为通道数据，支持实时波形显示、信号质量判断、分段存储，并将网络摄像头画面录制为关联视频。

技术核心由两条独立的数据链路构成：信号链路以样本队列为中心，视频链路以最新画面缓存和编码帧队列为中心。两者通过录制流程和文件名前缀建立关联，尚未建立统一的样本与视频帧时间轴。

适用代码基线：`0cb04efb9c3ec0828d2bbcc919a1d1700bb7d400`。

## 阅读路径

理解整体运行方式，先阅读系统架构，再沿信号采集、缓存、绘图和录制顺序阅读。接入新设备时，以二进制协议及摄像头流章节中的输入约束为准。处理视频时长、画面检测或 Android 后台问题时，结合跨平台视频编码与原生集成章节。

文件索引章节说明本地文件的延迟加载、增量更新和录制状态关联，不展开普通列表、分页样式或按钮实现。登录表单、国际化文本、简单配置控件及生成的示例工程不单独成章。

## 数据解释边界

- 信号协议固定为八通道；内存中的样本值为 `f32`，经过固定比例换算，不包含设备原始时间戳或序号。
- 信号文件中的时间戳是主机在样本进入录制队列时生成的 Unix 微秒时间；文件名中的时间戳是 Unix 毫秒时间。
- 波形横轴表示窗口内样本位置；信号与视频使用相同文件名前缀不代表逐样本同步。
- 滤波配置组件没有接入当前主界面及处理链路。现有信号路径执行协议解析、比例换算和质量统计。
- 各章节中的容量、阈值和帧率来自对应实现；理论容量换算不代表实际设备吞吐量或测量精度。
